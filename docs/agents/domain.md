# Domain docs

This repo uses one root `CONTEXT.md` and root `docs/adr/` for domain documentation.

Before exploring a domain area, read `CONTEXT.md` if it exists and any relevant ADRs in `docs/adr/`. Proceed if either is absent; domain-modeling creates these files when terms or decisions are established.

Use terms defined in `CONTEXT.md` in issues, proposals, and tests. Surface any conflict with an existing ADR explicitly.
