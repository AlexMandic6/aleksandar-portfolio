# Portfolio

This context describes the portfolio's published work and the visuals used to present it.

## Language

**Salon Booking**:
Aleksandar's in-progress personal project for booking services and appointments across different kinds of salons. Each installation serves one salon at one physical location; the project has a working customer booking flow and is not publicly hosted.
_Avoid_: Saloon Booking, saloon-booking

**Booking concept**:
A synthetic, noninteractive portfolio visual inspired by Salon Booking. It illustrates a possible flow and does not represent a product screenshot or a working demo.
_Avoid_: Booking app, booking demo

**Working hours**:
Recurring weekly intervals when a salon employee can be offered appointments. They are distinct from appointments customers have already booked.
_Avoid_: Booked times, appointment calendar
